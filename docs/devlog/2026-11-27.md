## Bugs caught tonight
- **Windows CI**: `orb.ts` and `Orb.tsx` are the same file on Windows, so the build broke
  (same for `dayRing`/`DayRing`, `deck`/`Deck`). Renamed, and a test now blocks
  module names that differ only in case.
- **Message order**: a reply could overtake the "thinking -> idle" states sent just
  before it. Each window now has one ordered outbox, and answers are queued from the
  same thread as the events.
- **Login start**: started by the orb from another folder, the core couldn't find `.env`
  (cloud fallback key). It now also looks next to the config.
